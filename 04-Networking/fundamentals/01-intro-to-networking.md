# Networking Fundamentals Overview

- Module roadmap: networking basics, network design, troubleshooting and cloud networking.
- Chapters build on one another.

## Topics

1. Networking fundamentals
   - LAN (Local Area Network) and WAN (Wide Area Network).
   - Routers, switches and firewalls.
   - IP addressing basics.

2. OSI model
   - How network communication fits into layers.
   - Where technologies and protocols fit.

3. DNS (Domain Name System)
   - Resolves domain names to IP addresses.

4. Routing
   - How packets travel between networks.
   - Routing protocols and how routers select paths.

5. Subnetting
   - Dividing IP networks into smaller networks.

6. Network troubleshooting
   - Diagnosing and fixing connectivity issues.

7. Cloud-native networking
   - Practical networking in AWS, Azure or GCP.

8. Hands-on networking
   - Real-world implementation examples.

## What to remember

- This lesson introduces the roadmap; detailed understanding comes in later lessons.
- DevOps relevance: configuring connectivity and troubleshooting communication between applications, servers and cloud resources.
