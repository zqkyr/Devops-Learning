# Networking Study Notes

This folder contains my networking revision notes from the DevOps curriculum.

Topics include IP and MAC addresses, ports and protocols, the OSI and TCP/IP models, DNS, routing, subnetting, NAT, troubleshooting and cloud networking.

The notes are organised into numbered Markdown files following the lesson order, with key concepts, useful commands and examples for quick revision.

Practical networking exercises and project documentation are stored separately in the networking assignments folder.
